# Electron 壳 0.9.1

- 包含 0.9.0 桌面功能：独立签名的后台与前端更新、受信启动器、后台恢复入口，以及任务、提问和审批通知。
- 修复 macOS 运行包内 PTY helper 的可执行权限，确保干净环境可直接启动终端。
- 验收关闭窗口隐藏到托盘、显式退出保留后台，以及安装、重开和修复后的配置与数据保留。
- macOS 仅提供 Apple Silicon 安装包，使用 ad-hoc 签名，尚无 Developer ID 签名及公证。

Includes the 0.9.0 desktop features: independently signed backend and frontend updates, a trusted launcher, recovery, and task, question, and approval notifications. Fixes executable permissions for the bundled macOS PTY helper. Acceptance checks cover closing to the tray, explicit exit while preserving the backend, clean installation, reopening, repair, and configuration/data preservation. macOS supports Apple Silicon only and uses ad-hoc signing without Developer ID or notarization.
