# Electron 壳 0.11.3

- Windows 安装器改用原生进程检测，移除 PowerShell/tasklist 检测分支；没有 Pulse.exe 进程时继续安装，检测失败时显示单独的错误代码。
- 检测到 Pulse.exe 时提示保存工作并退出，不再使用目录前缀批量终止进程。
- 捆绑后台与前端 0.11.2；安装和修复保留现有配置与会话。
- macOS 继续仅提供 Apple Silicon 安装包，使用 ad-hoc 签名，尚无 Developer ID 签名和公证。

## English

- Use native process detection in the Windows installer instead of PowerShell/tasklist detection; proceed when Pulse.exe is absent and report inspection errors with a separate error code.
- Ask users to save work and quit when Pulse.exe is detected, without terminating processes selected by a directory prefix.
- Bundle backend and frontend 0.11.2; preserve existing configuration and conversations during installation and repair.
- macOS continues to support Apple Silicon only with ad-hoc signing, without Developer ID signing or notarization.
