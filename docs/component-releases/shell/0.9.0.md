# Electron 壳 0.9.0

- 支持独立签名的后台与前端版本、受信启动器和后台不可用时的更新恢复入口。
- 新增任务、提问和审批通知及回到会话的入口，完善启动诊断和任务恢复前置检查。
- 精简内置运行环境，校验最终安装包的原生文件、签名与完整运行清单。
- macOS 仅提供 Apple Silicon 安装包，继续使用 ad-hoc 签名，尚无 Developer ID 签名及公证。

The shell supports independently signed backend and frontend updates, a stable launcher, and recovery when the backend is unavailable. It adds task, question, and approval notifications, startup diagnostics, and run-recovery checks. Bundled runtimes are smaller and final Mac artifacts undergo signature and manifest verification. macOS supports Apple Silicon only and continues to use ad-hoc signing without Developer ID or notarization.
