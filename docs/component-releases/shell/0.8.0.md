# Electron 壳 0.8.0 更新架构

- 支持独立后台与前端更新，安装包内置版本用于首次启动及恢复。
- 数据读取移至后台包提供的独立进程，壳不直接依赖数据库结构。
- 新增检查更新菜单；后台不可用时仍能通过内置受信入口查看和下载更新。
- 壳本身采用下载安装包的更新方式，macOS 沿用 ad-hoc 签名。

The shell supports independent backend and frontend updates and delegates data reads to the backend runtime. Update checks remain available when the service is offline. Shell upgrades use manual installer downloads; macOS continues to use ad-hoc signing.
