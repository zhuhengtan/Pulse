# Electron 壳 0.11.2

- 捆绑本次 0.11.2 后台和前端，包含任务验收、审批、预算、文档工具和会话展示的改进。
- 修复 preview 运行环境、版本及数据目录绑定，安装和修复保留现有会话、配置与后台数据。
- 保留后台与前端的独立签名更新、原生浏览器、通知和受信启动器。
- macOS 仅提供 Apple Silicon 安装包，使用 ad-hoc 签名，尚无 Developer ID 签名及公证；继续提供 Windows 和 Linux x64 安装包。

- 修复 Windows 安装时运行文件的保留。

## English

- Preserve Windows runtime files during installation.
- Bundle the 0.11.2 backend and frontend, including improvements to task acceptance, approvals, budgets, document tools, and conversation presentation.
- Fix preview runtime, version, and data-directory bindings while preserving existing conversations, configuration, and backend data during installation and repair.
- Retain independently signed backend/frontend updates, the native browser, notifications, and the trusted launcher.
- macOS supports Apple Silicon only with ad-hoc signing, without Developer ID or notarization; Windows and Linux x64 installers remain available.
