# Electron 壳 0.9.2

- 包含 0.9.0 桌面功能：独立签名的后台与前端更新、受信启动器、后台恢复入口，以及任务、提问和审批通知。
- 修复本地保存记录先于流式事件到达时，同一轮回复短暂重复显示的问题，并保留保存记录的正文与元数据。
- 保留 macOS PTY helper 权限修复，以及关闭到托盘、显式退出保留后台、安装、重开和修复后的配置与数据保留。
- macOS 仅提供 Apple Silicon 安装包，使用 ad-hoc 签名，尚无 Developer ID 签名及公证。

Includes the 0.9.0 desktop features: independently signed backend and frontend updates, a trusted launcher, recovery, and task, question, and approval notifications. Fixes a transient duplicate reply when local saved history arrives before its streamed text, while preserving canonical text and metadata. Retains the macOS PTY helper permission fix and acceptance coverage for tray lifecycle, installation, reopening, repair, and configuration/data preservation. macOS supports Apple Silicon only and uses ad-hoc signing without Developer ID or notarization.
