# Web/H5 0.8.0

- 桌面 Web 和手机 H5 共用独立前端更新包，可以脱离后台及 Electron 壳发布。
- 新增软件更新页面，显示版本、下载状态、兼容性和等待原因。
- 前端更新后提示刷新，保留编辑草稿，旧页面仍可加载旧版资源。

Desktop Web and mobile H5 share an independently published frontend. Update settings show versions and progress. Refreshing preserves composer drafts, and previous asset generations remain available.
