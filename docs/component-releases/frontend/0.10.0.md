# Web/H5 0.10.0

需要 Pulse 后台 0.10.0 或更高版本，桌面壳无需升版。

- 新增模型厂商接入向导，支持官方厂商、中间商和自定义 OpenAI 兼容接口。
- 新增本机 Ollama、官方 Ollama Cloud 和远程自托管接入；本机无需填写 Key。
- 自动导入全部对话模型，支持搜索、分页和能力筛选，并显示聊天、工具往返、JSON 输出的分项验证结果。
- 支持多账号与套餐、更新 Key 和刷新模型；Key 不进入浏览器持久存储，刷新保留已有模型与引用。
- 在存在未保存设置时保护草稿；保留原有环境变量和手工配置入口。

## English

Requires Pulse backend 0.10.0 or later. No desktop shell version change is required.

- Added a connection wizard for official providers, aggregators, and custom OpenAI-compatible endpoints.
- Added local Ollama, official Ollama Cloud, and remote self-hosted connections; local Ollama requires no API key.
- Import all conversation models with search, pagination, and capability filters, and show separate chat, tool-round-trip, and JSON-output verification results.
- Manage multiple accounts and plans, rotate keys, and refresh models; keys stay out of browser persistence, and refresh preserves existing models and references.
- Protect unsaved settings drafts and retain environment-variable and manual configuration paths.
