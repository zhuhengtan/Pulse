# Web/H5 0.9.0

- 新增独立组件版本、软件更新、技能市场与已安装技能管理页面。
- 更新刷新保留草稿，发送与重发保留完整消息及本次引用。
- 最终回复跨端一致，展开长消息后可正确展示和复制修订正文。
- 改善手机端会话详情、推理内容宽度与任务通知入口。

Web/H5 adds component-version and software-update settings, a skill marketplace, and installed-skill management. Refresh preserves drafts; sending and replay retain full message content and references. Final replies stay consistent across clients, expanded messages follow body revisions, and mobile conversation details, reasoning width, and notification navigation are improved.
