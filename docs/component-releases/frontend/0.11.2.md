# Web/H5 0.11.2

需要 Pulse 后台 0.11.2 或更高版本。

- 每轮任务结束后默认折叠公开过程，显示固定耗时，单独保留总结、产物及恢复操作。
- 置顶会话独立显示为可折叠的“置顶”区块，修复更新、回滚、持久化及重复显示，折叠箭头使用圆头细线。
- 统一浅色和深色中性色主题，减少无关框线、状态块和自动审批闪烁；保留手机和桌面操作入口。
- 提供命令放行列表、明确的长期放行操作及 256 次调用续额入口，保留安全授权与原始用量记录。
- 增加网页搜索与媒体工具设置、诊断和产物预览，并保留 Jarvis 个人记忆兼容说明。

## English

Requires Pulse backend 0.11.2 or later.

- Fold public progress after each completed task round, show fixed elapsed time, and retain summaries, artifacts, and recovery actions separately.
- Give pinned conversations an independently collapsible section, fixing updates, rollback, persistence, and duplicates, with rounded line disclosure arrows.
- Unify neutral light and dark themes, reducing unnecessary borders, status blocks, and automatic-approval flashes while retaining mobile and desktop controls.
- Provide command grants, explicit persistent-grant actions, and another 256-call allowance, retaining authorization and original usage records.
- Add web-search and media settings, diagnostics, and artifact previews, and retain Jarvis personal-memory compatibility guidance.
