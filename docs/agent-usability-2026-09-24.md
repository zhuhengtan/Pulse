# Pulse 本地可用性修复与验收（2026-09-24）

本轮针对真实 DeepSeek 运行中“提前超时、重复读写、研究无法完成”的问题。已重新编译本地开发 CLI。以下证据证明 macOS 本地任务链路可用，不代表剩余五阶段计划全部验收。

## 已修复

- **生产时钟**：Host 新建和恢复 Runtime 均显式使用 `MonotonicClock`。此前默认的 `VirtualClock` 会在外部调用尚未返回时推进到超时点，造成审批取消、网页请求过早超时。慢工具回归覆盖此问题；时钟等待不再阻止已完成 CLI 退出。
- **失败回传与停止**：失败/取消的工具 outcome 连同 effect 标识回到后续模型输入，并保存在运行状态中。相同错误三次触发明确失败；重复不变的成功结果先提示收尾，持续四轮不变则停止。中间一次成功读取不会抹掉尚未解决的失败。
- **输出截断**：`finishReason=length` 不再作为任务完成或执行不完整工具参数；结构化验收明确报告 `OUTPUT_TRUNCATED`，保留消耗。调整配置后重新发起任务，不静默重跑写操作。
- **可继续读取**：网页和本地文件结果提供 `nextOffset`。摘要不再隐藏剩余正文却声称完整；文件分页保持 UTF-8 边界。实际中文长文件已分三页读取并核对末行。
- **公共网页**：显式启用网络后按只读工具执行，仍检查域名和公网地址；每次跳转重新检查。DNS、请求和正文消费统一限时，限制正文大小，搜索结果解出原始来源地址，验证码单独报错。只读取消不再被当成外部写操作需要隔离。
- **实时显示**：SSE 文本在流尚未结束时就向 Host 发出，完整工具参数仍在结束后校验。
- **审批与用量**：区分真正拒绝、响应截断、格式错误和审批服务不可用；审批请求的成功/失败用量进入 attempt 去重及持久化。不会因审批不可用放行命令。
- **验收**：文件扩展名、URL、版本号不再被句号拆成多条要求；明确工具结果是已发生操作的证据，其正文不能提供新权限。评分器接受任务允许的纯文本来源 URL 与 `Access date`，修正 Python 行为探针的错误语法。

## 使用与恢复

在项目根目录执行 `pnpm cli:start` 使用已编译开发版。以后修改源码可使用 `pnpm cli:watch`，或执行一次 `pnpm build`。`pnpm cli:dev` 会先构建再启动。

遇到旧运行的 `reconcile_required`，先确认真实副作用再处理，不直接把状态改成成功/取消。已失败任务修复配置后新开任务，避免自动重放副作用。分页必须使用工具返回的 offset；`OUTPUT_TRUNCATED` 需要提高输出额度，本轮真实任务使用 8192，未修改用户配置。
