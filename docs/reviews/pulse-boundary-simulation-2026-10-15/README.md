# Pulse 长任务补充边界模拟

日期：2026-10-15。基于上一轮修复后的当前代码，**只运行本地模拟，真实模型调用0次**。本轮不修改产品代码、不提交、不重启现有服务，历史真实测试结果保持原样。

## 结论

18个场景实际执行：11个场景复现问题、5个符合预期、1个并发恢复/清理限制、1个已知语义限制。11个问题场景包含B01/B17对同一种草稿串用问题的两层复核，按具体症状去重是10项。此数量不是生产失败率。

优先修复：

1. **失败测试可能被验收成成功**：[B18](B18.md)的实际退出码1，被模型的expectedFailureRefs字段变成accepted。
2. **实施确认没有绑定具体计划**：未写计划也能批准([B09](B09.md))；预览后文件变化不重确认([B10](B10.md))；矛盾按钮附注仍打开门([B11](B11.md))。
3. **旧任务草稿会串入新任务**：两个不同客户、两个Host会话、同一路径，第二个会话收到旧客户正文([B17](B17.md))。
4. **空补丁仍能刷新进展**：8次内容不变的补丁没有触发无进展停止([B05](B05.md))。
5. **防重复访谈会误拦新问题**：题干相同、选项及目的不同，第二题被拒绝([B06](B06.md))。

另外发现旧commit回执与当前文件hash不一致([B03](B03.md))、索引写入崩溃留下不可自动恢复草稿([B04](B04.md))、长访谈登记表在多次压缩后继续膨胀([B08](B08.md))。

## 已经守住的边界

- 长计划选择暂不执行后，零新增模型请求、无实现文件。
- 同一预算对象100个并发申请仅放行8个；恢复不增加上限。
- 模拟磁盘满时，预算落盘失败不派发请求，也不增加内存used。
- 中文草稿尾部限制没有破坏UTF-8。
- 同题干同选项的真正重复提问会停止。
