# 任务产物与浏览器预览

工作模式的右侧是与聊天并排、从顶到底独立占位的标签窗口，不嵌套在旧预览面板中，也没有展开或收起状态。顶部统一显示文件、Diff、工具及浏览器网页标签；点击加号打开新标签页，可从工具入口查看文件、变更、终端或自动化。点击本轮交付卡片的“查看”、项目文件或聊天中的文件链接，可打开对应文件；同一路径在不同任务回合中的产物各自保留来源。预览支持文本/代码、Markdown、图片、PDF 和 HTML，其他格式可下载。图片支持缩放，PDF 支持翻页和缩放，文本按 1000 行分页。单文件登记及下载上限 128 MiB，直接预览上限 32 MiB。

产物读取会校验登记时的哈希。若文件已被后续任务修改，旧回合显示“文件已发生变化”，不会将当前内容冒充旧产物。项目文件展示当前内容。未合入项目的产物仍从实际执行目录读取。

HTML 使用有时效的预览入口，脚本运行在沙箱中，不能访问 Pulse 管理接口；支持相对路径与常见根路径资源。需要后端 API、登录或完整开发环境的应用，请通过浏览器标签访问真实开发服务地址。Pulse 不自动启动项目脚本。

## 浏览器标签

点击工作窗口顶部的加号，在新标签页地址栏输入网址并按 Enter，启用 browser 能力后即可打开浏览器。网页和文件共用顶部标签栏；连接现有 Chrome/Edge 的设置保留在“自动化”工具中。网页内容来自主机上的真实浏览器画面，支持不能嵌入 iframe 的页面。地址栏支持 HTTP/HTTPS、本地服务、新建/切换/关闭网页标签、后退与刷新。

Agent 打开浏览器时自动展示对应面板；主动隐藏后本次运行不会反复抢焦点。手动打开的网址可直接操作；AI 持有浏览器时点击“接管”后可点击、滚动，通过地址栏旁的输入按钮输入文本和快捷键，“交还 AI”后 Agent 会重新观察。切换或关闭面板不会停止浏览器。独立的“停止”操作才结束浏览器连接；连接现有浏览器时不会退出用户的 Chrome/Edge。

任务结束后浏览器保留页面与登录状态，并释放 Agent 控制。后续任务在同一工作会话中调用 `automation.open` 可复用浏览器。不同工作会话的专用浏览器配置目录隔离；旧的未绑定会话保持原有清理行为。服务重启后显示待重连，需要重新接管或交还 AI。

网络访问、设备授权和审批限制继续生效。模型侧新增 `browser.newTab`、`browser.closeTab`、`browser.back`、`browser.reload`；`browser.tabs` 返回带版本的结构化标签列表，切换/关闭支持携带版本以拒绝过期目标。任务身份由 Host 注入，工具参数不能选择其他工作会话。

H5 与桌面客户端共用预览链路。文件与浏览器入口及面板宽度保存在当前客户端；浏览器控制租约、实时画面和连接凭据不写入这些界面状态。移动端采用全屏面板。本期不提供 `sdk.js`。

## 代码差异

工作聊天中，成功的文件修改记录下方和助手文件链接旁提供“查看差异”。点击后在右侧打开独立的 `文件名 · Diff` 标签，显示增删行高亮和旧/新行号；可切换统一视图与左右对照。模式偏好及打开的标签在当前客户端保留，大差异分页显示。原有 Git 面板也使用相同的差异视图。

聊天入口比较会话实际执行目录中的当前工作区与暂存区；已暂存视图比较暂存区与 HEAD。未跟踪文件以新增内容显示。这里展示当前差异，不是某一历史任务回合的修改快照；已提交后当前范围可能没有差异，可通过刷新重新读取。
