# Web 富文本消息与附件

聊天和工作模式使用同一富文本输入框。桌面按 Enter 发送，Shift+Enter 换行或续列表；代码块内 Enter 换行，连续空行可退出代码块。手机 Enter 换行。输入 `/` 可选择技能，输入 `@` 可选择当前项目文件。文本格式、技能/文件标签及附件随会话草稿一起保留，切换会话不会混用附件。

消息会立即显示，同时清空对应会话的输入内容。发送失败时，若输入框还没有新编辑则恢复原文字、编辑结构和附件；已有新草稿时保留新草稿，原内容仍保存在失败消息中。失败消息在气泡左侧底部显示红色感叹号。点击后需要确认，才会重新发送原消息及附件。重试复用请求标识，响应丢失不会重复启动同一工作。聊天和工作模式都支持排队与立即发送；Cmd/Ctrl+Enter 在忙碌时使用本次另一种发送方式，不改变默认偏好。待发消息编辑使用同一 Tiptap 输入框。

## 附件

支持选择、粘贴和拖放文件。单次最多 10 个，单文件最多 20 MiB，完整消息请求最多 35 MiB；文件处理完成后才允许发送。较大 PNG/JPEG 会缩小，以满足现有模型图片输入上限。

- 文本和代码：按 UTF-8 文本窗口读取。
- DOCX：提取正文、段落及表格文字，按窗口读取；不还原排版，不识别内嵌图片，不支持旧版 DOC 或 OCR。解析有解压限制和 30 秒超时。
- PDF：按页及页内窗口读取可提取文字，不执行 OCR。
- XLSX：列出工作表，按指定工作表和行窗口读取，不计算公式。
- PNG/JPEG：通过图片 artifact 传递到支持图像输入的模型。没有已配置的视觉模型时，明确提示并保留附件。
- 其他二进制格式：可以下载，内容读取会明确返回不支持。

附件存放在会话数据目录，不复制到项目。只读工具 `attachment.read` 接受该会话已记录的附件 ID；不接受任意文件路径或远程 URL。文本/DOCX 使用 `offset`、`maxChars`，PDF 使用 `startPage`、`endPage` 和页内 `offset`，XLSX 使用 `sheet`、`startRow`、`maxRows`；历史附件较多时，使用 `attachment.list` 的 `query` 和 `offset` 分页查找 ID，避免把整个历史索引塞入模型上下文。结果中的 `nextOffset`、`nextPage`、`nextRow` 用于继续读取。附件引用随消息重试、历史压缩和任务恢复保留。

## 格式、快捷键与所见即所得

粗体、斜体、删除线、行内代码、链接、标题和引用在主动换行后不延续；自动视觉折行不受影响。列表继续下一项，空列表项换行退出。多行代码块是明确例外。粘贴 Markdown 按显式行分别解析行内格式，粘贴 URL 后继续输入不会扩大链接范围。

- `**粗体**`、`*斜体*`、`~~删除线~~`、反引号代码及 `[文字](https://example.com)` 支持输入转换。
- 行首 `# `、`## `、`### `、`> `、`- `、`* `、`1. ` 支持块格式；三个反引号后输入可选语言名和空格建立代码块。
- Cmd/Ctrl+B / I / E / K：粗体、斜体、行内代码、链接。
- Cmd/Ctrl+Shift+7 / 8：有序/无序列表；Tab / Shift+Tab：列表缩进/反缩进。
- Cmd/Ctrl+Alt+1 / 2 / 3 / 0：标题与正文；Cmd/Ctrl+Shift+B：引用；Cmd/Ctrl+Alt+C：代码块。
- 选中文字显示浮动工具条；链接编辑支持 Esc 取消，格式操作支持撤销/重做。

用户消息带有可选的 `richContent: { version: 1, document }`，使用经服务器校验的 Tiptap JSON 保存展示格式。Markdown `text` 继续供模型和搜索使用。格式、引用与附件贯通排队编辑、立即发送、重试、工作进程和历史加载；旧消息仍按 Markdown 显示。输入和消息复用排版及引用/附件组件，消息不用创建编辑器实例。

AI 消息支持 GFM、图片、代码高亮和 KaTeX。数学分隔符包括 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`，代码中的内容不参与公式转换。项目图片和产物图片复用现有受控文件接口；无效公式、加载失败图片和未完成的流式语法保留可读回退，不执行原始 HTML。

## 侧栏与验收

桌面会话栏默认 260px，可拖动到 220–420px，且不超过窗口宽度的 40%。拖至 180px 以下折叠；展开恢复之前的有效宽度。状态保存在本机浏览器，手机抽屉不会覆盖桌面宽度。

可重复的界面验收（先启动开发前端；自定义端口使用 `PULSE_RICH_UI_URL`）：

```sh
node scripts/web/verify-rich-ui.mjs
node scripts/web/verify-rich-ui-electron.mjs
```

浏览器脚本使用隔离会话夹具；Electron 脚本启动独立用户目录、临时 H5/SQLite，并验证实际 IPC 发送和刷新读取。模型使用 mock，不消耗真实 Provider 调用；脚本只关闭自己创建的窗口和服务。

## 层级文件引用与侧栏

输入 `@` 后按项目目录逐层浏览，当前目录内输入名称可筛选。`↑/↓` 选择，`→` 进入文件夹，`←` 返回上一级，`Enter` 插入选中的文件或文件夹；点击名称也会插入，点击右侧箭头进入目录。顶部路径可直接返回任意上级。目录引用保留完整路径和末尾 `/`，发送后的标签点击会打开对应目录。读取目录期间 Enter 不发送消息，Escape 关闭选择器。

侧栏项目和会话行支持右键菜单；会话悬浮显示置顶、归档操作及项目/目录详情。项目标题旁的整理菜单可切换分项目/合并展示，以及最近更新/创建时间排序；这些展示偏好保存在本机，不改变会话所属项目。菜单复用已有的重命名、置顶、移动和归档能力。

可重复验收：`node scripts/web/verify-hierarchy-sidebar.mjs`；加 `--electron` 会启动隔离的实际 Electron 窗口。验收使用合成项目与会话数据，不操作真实项目或调用模型。

项目顺序现在通过拖动项目行保存；触屏可拖动文件夹图标。项目操作隐藏时不占用名称宽度，悬浮或键盘聚焦后显示。展开/折叠分别使用 Ant Design 的打开/关闭文件夹图标。双击会话标题可打开重命名弹窗；悬浮长标题会在短暂停顿后以 48px/秒播放一次，移开鼠标复位，并尊重系统的减少动态效果设置。

项目菜单中的“编辑项目”可修改名称、添加/替换/移除源文件夹，以及设置主文件夹。至少保留一个文件夹；保存前校验真实目录。主文件夹用于新会话默认工作目录，已有会话不迁移执行目录。目录列表不自动扩展已有任务的工具授权范围。

这组交互的隔离真实后端验收：`node scripts/web/verify-project-sidebar.mjs`，或增加 `--electron`。脚本使用临时项目、临时用户目录和当前前端构建，不替换运行服务的静态资源。

悬浮项目行会在右侧展示项目信息卡，包括聊天数量、源文件夹和主要目录。卡片右上角可置顶/取消置顶，底部可进入编辑项目。长会话标题静止时显示省略号；悬浮播放时隐藏省略号。
