# 通用任务执行：v20 变更与验证边界

本轮实现针对可复现的参数纠错、检查范围、能力发现、GUI 阶段判定和预算连续性缺陷。它不构成“任意任务均可完成”的证明，也不包含发布、生产迁移或服务重启。

## 接口与兼容

- 新工作运行使用 task-controller v20；新普通 ReAct 使用 v4.1，新助理使用 v4。旧版本继续注册。参数预检只在新版本启用，工具定义在纯步骤之外捕获。
- `INVALID_TOOL_INPUT` 可附带安全的结构化 `details.issues`（字段路径、类型与上下限）。不包含输入值或自定义 schema 错误文本。纠错有界，参数改变清除旧批准绑定，普通审批与本地审批转人工后的恢复均重新校验。
- `CheckReceipt.schemaVersion=2` 增加 `scope`：输入路径、explicit/project 及 coverage。SVG、CSV 等实际命令输入被哈希；定向范围在复查时固定，独立新增脚本不改变旧检查范围。定义/被测输入改变仍需重验。动态依赖标为 `unknown-dynamic`，不声称完整覆盖。v1 回执沿用旧范围算法。
- `capability.status` 返回浏览器/桌面工具是否注册、配置是否启用、连接状态和阻塞建议。诊断不安装软件，不自动扩权；桌面系统权限不能确认时标为 unverified。
- 新运行保存能力面版本和模型信息；`TaskOutcome` 增加可选 blockers/interventions。Runtime 结束和任务验收继续分开记录。
- 新控制器恢复/继续从持久预算继承剩余额度，冷进程恢复不清零。助理 v4 同样受持久模型调用预算约束。评测器额外对整个批次及失败任务重试累计收费；助理转交评测为父子运行各分配一半额度。这不是产品级任意委托树共享预算的完整实现。
- v20 最终验收显式要求 criteria 外层，Provider 拒绝的格式输出允许一次纠正；预算、原始断言与证据规则保持强制。再次格式错误仍为 incomplete。
- 明确描述上次中断并要求继续剩余工作的完整句子继承任务与预算；新任务和不要继续的表述不进入该分支。
- GUI 操作阶段不再强制要求文件写入；显式文件/代码交付仍要求相应证据。新助理识别启动工作会话的自然语言请求，避免把委托任务中的读文件要求错误地强加给助理本身。

## 可复查入口

- 历史审计：`scripts/eval/audit-history.mjs`，只读归集并按会话/run 去重，不重写历史评分。缺失版本/模型等字段保留 null；历史 accepted 不等于独立验收通过。
- 固定回归映射：`evals/autonomy-regressions.v1.json`。
- 确定性回归：`tests/autonomy-{recovery,capabilities,audit,interface}.test.ts`，以及预算、continuity、LT02、独立验收原有测试。
- 真实任务：`scripts/eval/autonomy-{live,browser,cold,handoff,long,general}.mjs`。默认 deepseek/deepseek-flash；批次800次、逻辑任务64次。所有失败尝试保留；审批须由评测者读具体操作后写入匹配摘要的决定。
- 本轮本地证据：`.pulse-dev/autonomy-20261022/`，最终结果见该目录 `REPORT.md`。这些生成数据默认不进入 Git。
- 现场入口：`scripts/eval/autonomy-electron-existing.mjs` 使用原开发后台 7333 和 `.pulse-dev/h5/data`；题目提交和逐项审批通过原 Electron 客户端完成。测试项目、对话、产物和失败记录保留。`autonomy-ui-review.mjs` 只记录已审查的具体操作，不自动点击批准。
- 现场后台配置保持原样（256 次上限）；评测观察器在本次运行达到 `min(32, 剩余额度 - 8)` 时请求取消，给在途调用保留余量。该配置与独立宿主 64 次硬上限不同，结果分组报告；不把观察器当作产品级预算硬保证。完成首轮后，若下一轮样本不能预留完整 64 次，则结束本批并保留余额。

## 不能据此宣称的能力

提示词对一次性界面操作的约束不是严格的副作用幂等协议。浏览器/桌面和研究来源的真实验收仍需独立证据；命令成功、文件存在或模型自述不能单独证明任务完成。动态输入发现、任意外部系统的未知写入结果、跨委托树预算以及完整通用基准仍需进一步验证。
