# CLI 界面修正验收（2026-09-24）

本次针对 Mac 翻页、内部验收文本混入回答、界面拥挤三个问题。

- Host 对外 text 事件只发布最终选中的回答。模型候选回答和 verifier JSON 不作为正文推送；工具和任务状态继续实时更新。代价是回答会在本轮执行及验收结束后出现，不逐 token 展示候选稿。
- 工具默认合并为一行计数，失败仍可见；`/verbose` 查看参数和结果。移除无法操作的逐条展开提示和正文里的私有思考字段。
- 默认启用 SGR 鼠标报告：滚轮/触控板每个纵向滚动事件移动三行，连续事件累计；点击、松开和横向滚动不作为正文或输入。`/mouse off` 恢复终端原生选字，`/mouse on` 重新开启；退出自动关闭鼠标报告。
- Ctrl+P 上翻、Ctrl+N 下翻、Ctrl+G 回到底部；保留 PageUp/PageDown（Mac 可使用 Fn+↑/↓）。↑↓ 继续浏览输入历史。
- 根据终端实际行宽处理中文和 ANSI 换行；翻页时保留阅读位置。状态栏合并，移除重复工作目录、lane ID、目标文本和高亮代码背景。
- 替换会把 Ctrl 快捷键字母插入草稿的输入组件；字符移动、删除以完整 Unicode 字素处理。

验证：

- `pnpm build` 通过。
- `pnpm test`：99 个测试文件、684 项通过（不包含真实 Provider live 测试）。
- 新增真实 Provider SSE 协议的模拟回归：第一稿 → replan 验收 JSON → 修正稿 → accepted，Host 对外及持久化只含修正稿。
- 本机 macOS PTY 交互：100×28、60×20，50 行中文长回答；Ctrl+P/N/G、窗口缩放、中文草稿在翻页时保留均通过。另验证滚轮事件连续上/下滚、点击不污染输入、`/mouse off/on` 切换、退出清理及连续退格。滚轮解析新增 1 项定向测试通过。发现并修复旧输入组件把 `p` 插入草稿的问题。

边界：本轮 PTY 使用隔离数据目录及 mock 模型，只验 UI；滚动测试注入终端 SGR 事件，未操作物理触控板。未据此宣称真实模型质量或 Windows/Linux 终端验收。当前已运行的 CLI 仍加载旧代码，需退出并重新启动；不自动终止用户会话。旧会话中已保存的正文不做破坏性清洗。
